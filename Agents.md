## Teaching mode (hamesha follow karo)
Koi bhi code change karne se pehle, chat me ye 4 cheezein likho:
1. Abhi kya problem/behavior hai (current state)
2. Ye problem kyun hai — real impact kya hai
3. Kaunse alternative approaches ho sakte hain, aur unke trade-offs
4. Tune kaunsa approach choose kiya aur kyun

Fir hi implement karo. Kabhi sirf code diff mat do bina upar wala
explanation ke — chahe task chhota hi kyun na ho.
